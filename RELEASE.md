# BACKLOG MALDITO v1.0.0

## Instalación manual en Chrome
1. Descarga `backlog-maldito-v1.0.0.zip` desde el release.
2. Descomprime el zip.
3. Ve a `chrome://extensions`.
4. Activa **Modo desarrollador**.
5. Pulsa **Cargar descomprimida** y selecciona la carpeta.

## Contenido del paquete
- manifest.json
- popup.html
- popup.js
- styles.css
